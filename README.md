# 나의 헬스플랜 (My Health Plan) 🏋️‍♂️

> 하이클래스짐 동천점 실제 머신 가이드 기반 스마트 운동 플래너 & 트래커

배포 사이트: [https://hyochanie555.github.io/myHealth/](https://hyochanie555.github.io/myHealth/)

---

## 📅 주간 루틴 가이드
* **월요일 / 목요일**: 상체 집중 데이 (체스트프레스, 랫풀다운, 펙덱플라이, 시티드로우, 숄더프레스, 사레레, 딥스, 행잉니레이즈)
* **화요일 / 금요일**: 하체 집중 데이 (레그익스텐션, 레그프레스, 브이스쿼트, 라잉레그컬, 인앤아웃타이, 힙쓰러스트, 행잉니레이즈, 사이드벤드)
* **수요일 / 토요일**: 유산소 버닝 데이 (트레드밀 인클라인 경사 걷기, 천국의 계단/스텝밀, 실내 사이클 50분)
* **일요일**: 스트레칭 & 폼롤러 회복 데이 (모빌리티 회복 및 관절 이완)

---

## ⚡ 주요 기능
1. **오늘 운동 완료 및 사라짐(Dismiss) 기능**:
   * 각 기구 카드의 [오늘 완료 ✔] 버튼을 누르면 기분 좋은 사운드와 함께 카드가 사라지며 **남은 운동만 한눈에 확인**할 수 있습니다.
2. **동천점 머신 도감 33종 연동**:
   * 실제 하이클래스짐 동천점에 비치된 최고급 머신들의 사진, 좌석 세팅법, 자극 팁, 주의사항 수록
3. **세트 간 휴식 타이머 & 유산소 50분 전용 타이머**:
   * 45초 / 60초 / 90초 원클릭 세트 휴식 타이머 (비프음 및 진동 알림)
4. **운동 일지 & 캘린더 기록**:
   * 하루하루 완료한 운동과 메모가 브라우저 LocalStorage에 안전하게 저장되며, JSON 백업 및 복원 지원
